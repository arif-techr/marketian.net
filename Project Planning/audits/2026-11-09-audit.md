## Findings
1. **High:** `wa-broadcaster/` (old standalone copy) is untracked and **not ignored**. It contains `backend/.venv`, `frontend/node_modules` and `backups/*.sql` (4 dumps from 2026-10-15, probably with contacts' phone numbers). A `git add .` would publish them. Fix: move the folder out of the repo, or add `wa-broadcaster/` to `.gitignore`.
2. **Low:** `sites/wa/backend/db.sqlite3-journal` is untracked and not ignored. Fix: add `*.sqlite3-journal` to `.gitignore`.
3. **Low:** `sites/wa/package.json` scripts `docker:up/down/logs` assume a standalone compose file. It now needs the repo root, and the UI no longer publishes a port.
4. **Medium:** marketian, accounts and metadata default to `DEBUG=True` and `SECRET_KEY=dev-insecure-change-me` when the `.env` lacks them. The `.env.example` files set `DEBUG=False`, so this only bites on a hand-written `.env`. Suggested: refuse to start with the placeholder key when `DEBUG` is off, or default `DEBUG` to False.
5. **Info:** no `.env` files exist on the PC, which is expected. Local runs use the defaults.
